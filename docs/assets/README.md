# Assets (screenshots / demo video)

Add portfolio-ready media here:

- `screenshot-feed.png`
- `screenshot-post-detail.png`
- `screenshot-explore.png`
- `screenshot-profile.png`
- `demo.webm` (30–90 seconds)

This repo can generate these automatically:

```bash
pnpm run portfolio:artifacts
```

Recommended capture checklist:

- Use the same seed data/user for consistency
- Show the evaluator path: login → feed → AI suggestions → post detail → explore/search → profile follow/unfollow
- Prefer a 16:9 recording at 1080p, with reduced-motion enabled if your OS supports it
