# Stories (Build Log)

The files in `docs/stories/` are chronological “making of” notes written during implementation. They are intentionally
preserved as a build log, which means some details may reflect earlier iterations.

If something in a story conflicts with the current codebase (for example: early Next.js versions, Redux usage, or the
previous `packages/shared-types` workspace), treat the story as historical and use these as the source of truth:

- Current architecture: `docs/architecture/README.md`
- Interview-ready overview: `docs/interview/README.md`
- Evaluator path: `docs/evaluator-guide.md`
